# 🩺 Medical Chatbot (GenAI + RAG Powered)
An intelligent medical assistant chatbot built using Generative AI and Retrieval-Augmented Generation (RAG) to provide context-aware, reliable, and explainable healthcare responses.
This project demonstrates how modern LLM systems can be enhanced with domain-specific knowledge retrieval to reduce hallucinations and improve response accuracy in sensitive domains like healthcare.

### 🚀 Key Highlights
* •	🧠 LLM-powered conversational AI
* •	📚 Retrieval-Augmented Generation (RAG) for grounded responses
* •	🔎 Context-aware medical query handling
* •	💬 Interactive chatbot interface
* •	🛡️ Reduced hallucination via external knowledge retrieval
* •	⚡ Modular and extensible architecture


### 🛠️ Tech Stack
* •	Python 🐍
* •	LangChain / LangGraph (for orchestration)
* •	Vector Database (FAISS / Pinecone)
* •	Transformers / LLMs (GPT / HuggingFace)
* •	Embeddings Models
* •	Flask / Streamlit


### ⚙️ Installation & Setup
* 1. Clone the repository
  * git clone https://github.com/sharma-srishti/Medical-Chatbot.git
  * cd Medical-Chatbot
* 2. Create virtual environment
  * python -m venv venv
  * source venv/bin/activate   # Windows: venv\Scripts\activate
* 3. Install dependencies
  * pip install -r requirements.txt
* 4. Run the application
  * python app.py
